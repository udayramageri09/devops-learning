# Day 01 — Filesystem Commands

| Command       | Purpose               | What I observed                   |
|---------------|-----------------------|-----------------------------------|
| `pwd` | Shows current working directory | Shows where the terminal is currently located |
| `ls` | Lists files and directories | Displays contents of current directory |
| `mkdir` | Creates a directory | Created `test-devops` |
| `cd` | Changes current directory | Moved into `test-devops` |
| `New-Item` | Creates a new file | Created `notes.txt` |
| `Get-Content` | Reads file contents | Displayed contents of `notes.txt` |
| `Copy-Item` | Copies a file | Created a copy of `notes.txt` |
| `Rename-Item` | Renames a file | Renamed the copy to `backup.txt` |
| `Remove-Item` | Deletes a file | Deleted `backup.txt` |

## Important Concept

A filesystem organizes data into:

- Files
- Directories
- Paths

The terminal allows us to interact with the filesystem using commands.
